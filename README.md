# InclusivePulse — Accessibility & Usability Evaluation Engine

> A lightweight, zero-dependency accessibility testing and evaluation lab built with semantic web standards to validate WCAG 2.1 AA/AAA compliance and Universal Design principles.

## Core Modules
- **Keyboard & Focus Architecture:** Features roving tabindex navigation, modal dialog focus traps, accessible accordions, and custom ARIA menu button patterns.
- **Contrast & Compliance Engine:** Real-time relative luminance calculation with an automated 6-point WCAG & APCA compliance evaluation and passing color suggestion tool.
- **Accessible Form Validation:** Inline ARIA error states (`aria-invalid`, `aria-describedby`), accessible error summaries, and format assist patterns.
- **Image Accessibility Tracker:** Automated heuristic evaluator checking alt-text completeness, non-text contrast, and decorative vs. informative image classification.
- **Real-Time Event Stream:** Live keyboard interaction logger tracking focus order and keydown signatures.

## Tech Stack
- Semantic HTML5 (WAI-ARIA APG Patterns)
- Tailwind CSS & Custom CSS Variables (Dynamic Theme Switching)
- Vanilla JavaScript (Mathematical Relative Luminance Engine)
